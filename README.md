# YouTube UI Clone

A clean, responsive, and interactive frontend clone of the YouTube user interface. Built entirely with single-file HTML, utilizing Tailwind CSS for styling and Vanilla JavaScript for dynamic functionality. 

## ✨ Features

* **Responsive Design:** Fully responsive layout that adapts flawlessly to desktop, tablet, and mobile screens. Includes a mobile-specific bottom navigation bar and a collapsible sidebar.
* **Real-Time Search Filtering:** The search bar is fully functional. Typing into it instantly filters the video grid below based on video titles and channel names without page reloads.
* **Modern Styling:** Built with Tailwind CSS (via CDN) matching YouTube's dark mode color palette (`#0f0f0f` background, exact hover states, and borders).
* **Material Symbols:** Uses Google's Material Symbols for authentic, lightweight iconography.
* **Custom Scrollbar:** Webkit-styled scrollbar to match the native YouTube desktop experience.
* **Mock Data Integration:** Dynamically renders the video grid using JavaScript arrays, complete with view counts, upload times, and dynamic thumbnail/avatar color generation.

## 🛠️ Technologies Used

* **HTML5** (Semantic structure)
* **Tailwind CSS** (via CDN for rapid, utility-first styling)
* **Vanilla JavaScript** (ES6+ for DOM manipulation and search logic)
* **Google Fonts & Icons** (Roboto font family & Material Symbols)
